# Movie Catalog API

## Краткое описание проекта
Простое REST API для каталога фильмов, разработанное на фреймворке FastAPI. Проект позволяет добавлять информацию о фильмах и получать их список с возможностью фильтрации и сортировки. Вся логика приложения, модели и настройки базы данных объединены в одном файле `main.py` для удобства запуска.

## Основные возможности приложения
- Добавление нового фильма в базу данных (название, режиссёр, год выпуска, рейтинг).
- Получение списка всех фильмов.
- Фильтрация фильмов по имени режиссёра.
- Сортировка списка по году выпуска (по возрастанию) или по рейтингу (по убыванию).
- Пагинация (пропуск записей и ограничение их количества при выводе).
- Автоматическая генерация интерактивной документации Swagger UI.

## Технологический стек
- **Язык программирования:** Python 3.9+
- **Веб-фреймворк:** FastAPI
- **ORM (работа с БД):** SQLAlchemy
- **База данных:** SQLite (локальный файл `movies.db`)
- **ASGI-сервер:** Uvicorn
